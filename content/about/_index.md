## 01. Development & Systems

When building software, I prefer straightforward solutions, clean code, and predictable tools:

- **Low-Level Languages (C and Rust):**  
  I enjoy learning how software operates under the hood. In C, I study memory management, algorithms, and data structures. In Rust, I leverage type safety to build tools like a macro library for composing dynamic SQL queries with SQLx.

- **Declarative Systems with Nix & NixOS:**  
  I use Nix and NixOS to keep my workstations and development setups reproducible. This is the foundation I used to build `toof-os`, the operating system tailored for the **DACC Station** (an arcade console project at UNIR running on Raspberry Pi 4).

- **Web Development:**  
  I work with TypeScript, React, Next.js, and Laravel, using relational databases like PostgreSQL and MySQL, and Docker to standardize local team services.
